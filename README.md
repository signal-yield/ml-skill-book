# ml-skill-book

『AIエージェントで機械学習をスキルにする』（松田幸一、Signal Yield Advisory）の配布ファイルです。本書と同じデータとプログラムで、本書と同じ数値を再現できます。

## 入っているもの

| フォルダ | 中身 | 使う章 |
|---|---|---|
| `data/` | 本書で使った取引価格のCSV（2026年10月11日に取得した教材版） | 第2章〜第8章 |
| `ch01/` | 二つの広告の㎡単価を比べるプログラム | 第1章 |
| `ch02/` | CSVの列と件数を確かめるプログラム | 第2章 |
| `book/` | 選別、回帰、評価、範囲の確認、モデルの書き出しのプログラムと、そのテスト | 第2章〜第8章 |
| `skill/mansion-price/` | 第7章・第8章で作るスキル（SKILL.md、predict.py、model.json、テスト） | 第7章・第8章、付録 |
| `verification/` | 各章で何を確かめたかの検証記録 | 巻末 |

## 準備

Python 3.12 と、NumPy・pandas・Matplotlib を使います。Windows の PowerShell での例です。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy pandas matplotlib
```

一行目は、このフォルダ専用のPythonの環境（仮想環境）を作る命令です。二行目は、そこに三つのライブラリを入れる命令です。

## 実行の例

`book` フォルダに移動し、CSVの場所を引数で渡します。

```powershell
cd book
..\.venv\Scripts\python.exe ch04_regression.py "..\data\Tokyo_Setagaya Ward_20211_20254.csv"
```

`training_csv.py` は、CSVの指紋（SHA256）と行数を確かめ、本書と同じ乱数の種（20261011）でトレーニングデータとテストデータに分けます。CSVが教材版と違えば、その時点で止まります。

本書と同じトレーニングデータとテストデータに分けるには、次の三つがそろっている必要があります。`training_csv.py` は、この三つを満たす形で分けます。

1. 同じファイルであること（SHA256 で照合する）
2. CSV のすべてのデータ行を、元の行の順番どおりに読み込むこと（価格情報区分や駅で絞り込む前）
3. 同じ並べ替えの手順と乱数の種を使うこと（行番号の一覧を `random.Random(20261011).shuffle` で並べ替え、先頭から全件数の8割（端数は切り捨て）をトレーニングデータ、残りをテストデータにする）

テストは、`book` フォルダで `python test_ch03_select.py` のように、ファイルごとに実行します。スキルのテストは、`skill/mansion-price` フォルダで `python tests/test_predict.py` を実行します。

## 本文との違い

- `ch01`・`ch02`・`book` のプログラムは、本文に載せたものと同じです。
- 第7章・第8章のスキルは、本書の点検を受けて直した後の版です。入力の確かめ方と、誤差の説明文が、物語の中の版と違います。違いは第8章と巻末に記しています。
- `ch05_evaluate.py` はテストデータの価格を読みます。本書でテストデータを使った経緯は、巻末「本書の検証について」に記しています。自分でモデルを変えるときは、テストデータを開く前に、トレーニングデータの中で比べて決めてください。

## データの出典

出典：国土交通省 不動産情報ライブラリ（https://www.reinfolib.mlit.go.jp/）

`data/` のCSVは、不動産情報ライブラリからダウンロードした東京都世田谷区・中古マンション等の価格情報（2021年第1四半期〜2025年第4四半期）で、ファイルには手を加えていません。不動産取引価格情報と成約価格情報の二つが含まれ、本書では不動産取引価格情報だけを使います。本書のプログラムによる選別・集計の結果は、このデータをもとに著者が作成したもので、国土交通省が作成したものではありません。

公開データは更新されることがあります。新しくダウンロードしたCSVでは、件数や数値が本書と変わる場合があります。
