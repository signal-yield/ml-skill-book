# mansion-price

世田谷区の東急田園都市線沿線6駅の中古マンションについて、最寄駅・徒歩分数・面積・建築年・改装の有無から、2025年の取引価格の水準での予測値を返すスキルです。

## 置き場所
作業フォルダの `.agents/skills/mansion-price/` に、このフォルダの中身をそのまま置きます。

## 使い方
Codexのチャットで、たとえば「用賀、徒歩6分、70㎡、2005年築、未改装のマンションの価格の予測値を出して」と頼みます。足りない項目があれば、聞き返されます。

## 返るもの
- 総額と㎡単価の予測値（2025年の取引価格の水準）
- 予測の誤差（モデルづくりに使っていない取引での、差の大きさ）
- データに含まれていない価格形成要因
- 予測できる範囲

## 返らないもの
- 売り出しの価格や、いま売れる価格
- 予測できる範囲の外の物件の予測値（理由を返して止まります）
- その物件を買うべきかどうかの判断

## 中身
- SKILL.md：スキルの定義ファイル（Codexが読み込む）
- scripts/predict.py：予測の計算
- assets/model.json：モデルの係数と範囲（取引一件ごとの価格は含みません）
- tests/test_predict.py：動作の確認
