# マンションの取引価格の予測

## 入力
次の五つを、ユーザーから聞き取る。足りないものがあれば、推測で埋めずに聞き返す。
- 最寄駅（用賀、池尻大橋、三軒茶屋、駒沢大学、桜新町、二子玉川のいずれか）
- 最寄駅からの徒歩分数（分）
- 面積（㎡）
- 建築年（西暦）
- 改装（未改装か改装済み。広告に記載がなければ聞き返す）

取引年は2025年だけを受け付ける。2025年以外が指定されたときは計算せず、日本語の理由を返す。
徒歩分数・面積・建築年を数値にできないときや、改装が「未改装」「改装済み」以外のときは、推測で補わず入力を確認する。

## 手順
1. 聞き取った五つと取引年を、次の形のJSONにする。
   {"station": "用賀", "distance": 6, "area": 70, "built_year": 2005, "renovation": "未改装", "year": 2025}
2. scripts/predict.py に、そのJSONを渡して実行する。計算は自分でしない。
3. 出力をそのままユーザーに見せる。

## 出力
- 予測できた場合：総額と㎡単価の予測値、予測値の意味（meaning）、予測の誤差（error）、データに含まれていない価格形成要因（not_in_data）、予測できる範囲（scope）
- 予測できない場合：その理由（reasons）と、予測できる範囲（scope）
- meaning、error、not_in_data は、言い換えたり省いたりせず、そのまま見せる
- error は実際の取引価格に対する差の大きさの割合で、高く予測したか低く予測したかは区別しない。数値はモデルに保存された確認済みの記録を使い、テスト用価格を読み直さない。
